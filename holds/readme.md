## Tạo bộ dữ liệu mẫu (Lorem/Dummy data) test

1. Bơm dữ liệu test tự động: Gõ node scripts/lorem-seed.local.mjs → mở trang Admin và bấm Ctrl + F5 là có sẵn đầy đủ biểu đồ, đơn hàng, kho key và sản phẩm để test.
2. Dọn sạch 100% trước khi Go-Live: Gõ node scripts/lorem-seed.local.mjs --clean → toàn bộ dữ liệu mẫu tự động biến mất khỏi Database.
